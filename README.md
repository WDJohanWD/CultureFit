# Proyecto fin de ciclo, CultureFit

CultureFit es una plataforma web desarrollada como proyecto de fin de ciclo que combina tecnología y pasión por el deporte para ofrecer una experiencia completa de gestión para gimnasios y usuarios avanzados.

El objetivo principal es brindar un entorno digital especializado donde atletas, culturistas, powerlifters y entusiastas del fitness puedan:

Gestionar su suscripción a un gimnasio especializado.

Acceder a contenido exclusivo de entrenamiento y nutrición.

Reservar citas con profesionales como fisioterapeutas y nutricionistas.

Disfrutar de una experiencia personalizada, tanto presencial como online.

La plataforma incluye una aplicación web desarrollada con Spring Boot y React, y cuenta con una estructura sólida para escalar el negocio, ofrecer servicios híbridos y conectar a los usuarios con recursos de alto nivel.
